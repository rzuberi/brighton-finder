# brighton-finder

Home hunting site for Brighton. Scrapes Zoopla, Rightmove and OpenRent once a day (3+ bedrooms, up to £2,500 pcm), merges duplicate listings and puts everything on one page with filters, a map and walking times.

Live at [rzuberi.github.io/brighton-finder](https://rzuberi.github.io/brighton-finder/).

The scraper lives in the [flat-finder](https://github.com/rzuberi/flat-finder) repo (`config/brighton.json`); this repo holds the published site and its data.
